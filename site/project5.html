Project 05

Migration of Cotswold Drone Pilots from Wix to AWS

Website rebuild, AWS hosting, DNS migration and domain transfer with minimal downtime.

Completed

Project Overview

This project involved migrating the Cotswold Drone Pilots website away from Wix and onto an AWS-hosted architecture while preserving the existing domain name, Google Workspace email service and associated DNS records.

The migration was designed to separate the website from the previous hosted platform, move domain and DNS management into AWS, and complete the cutover with minimal disruption to both the website and email.

Website Build

The Cotswold Drone Pilots website was rebuilt as a static site using HTML, CSS and media assets, removing the dependency on the Wix website builder and hosting platform.

  • Rebuilt static website using HTML and CSS
  • Responsive layout for desktop and mobile
  • Separate portfolio and fleet pages
  • Video content and imagery optimised for web delivery
  • Reusable navigation and styling across the site
  • Local testing completed before AWS cutover

AWS Infrastructure Build

The new site was deployed using AWS services designed for secure, highly available static website delivery.

  • Amazon S3 used to store the website files and media assets
  • Amazon CloudFront used as the global content delivery layer
  • AWS Certificate Manager used for HTTPS/TLS certificates
  • Amazon Route 53 used for authoritative DNS hosting
  • CloudFront configured for both the root domain and www hostname
  • Default root object configured as index.html

Domain Registration Transfer

Domain registration for cotswolddronepilots.com was transferred away from Wix and moved into AWS, bringing the website, DNS and domain management under the same cloud platform.

The Route 53 hosted zone was prepared before the nameserver cutover so that the DNS configuration was already in place when control moved away from Wix.

Preserving Existing DNS Records

A key requirement was to preserve the existing Google Workspace email service. The DNS records required for mail delivery and domain verification were recreated in Route 53 before the nameserver change.

  • Google Workspace MX records preserved
  • SPF TXT record preserved
  • Google site verification TXT record preserved
  • Existing domain verification records retained
  • Inbound and outbound email tested after migration

Migration Workflow

Rebuild website → create S3 hosting environment → configure CloudFront → request and validate ACM certificate → create Route 53 hosted zone → recreate DNS records → configure CloudFront custom domains → transfer domain registration → update nameservers → create Route 53 aliases → test website and email.

Minimal-Downtime Cutover

The migration was carried out in stages so that the new AWS environment was ready before DNS control changed. This allowed the website and email configuration to be validated before final cutover.

By preserving the existing DNS records and preparing the AWS infrastructure in advance, the domain could move from Wix to AWS with minimal interruption to public website access and no loss of Google Workspace email functionality.

Project Outcome

Completed. The Cotswold Drone Pilots website was successfully moved from Wix to AWS, with the site rebuilt and hosted through S3 and CloudFront, DNS moved to Route 53, the domain registration transferred to AWS and Google Workspace email preserved throughout the migration.
